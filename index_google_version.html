Hướng Dẫn Cấu Hình Cổng Google API (Chỉ 2 Phút)

1 Cách 1: Dùng Google Apps Script Web App (Siêu nhanh, không cần cài đặt phức tạp)

Dễ nhất
  1. Truy cập script.google.com và bấm Dự án mới (New Project).
  2. Xóa mã mặc định và dán đoạn mã sau vào:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    GmailApp.sendEmail(data.to, data.subject, "", {
      htmlBody: data.body,
      name: data.fromName || "Hệ Thống"
    });
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Bấm Triển khai (Deploy) > Tùy chọn triển khai mới (New deployment).
  2. Chọn loại bánh răng: Ứng dụng web (Web app).
  3. Mục "Ai có quyền truy cập" (Who has access): Chọn Bất kỳ ai (Anyone) > Bấm Triển khai & Cấp quyền tài khoản Google của bạn.
  4. Sao chép URL kết thúc bằng /exec và dán vào ô Web App ở Bước 1 của trang web này!

2 Cách 2: Dùng Google OAuth 2.0 (Gmail API Trực Tiếp)

Chuẩn Google Cloud
  1. Vào Google Cloud Console > Tạo Project mới.
  2. Vào APIs & Services > Library > Tìm Gmail API và bấm Enable.
  3. Vào OAuth consent screen > Chọn External > Điền tên ứng dụng & email của bạn > Thêm email của bạn vào danh sách Test users.
  4. Vào Credentials > Create Credentials > OAuth client ID > Chọn Web application.
  5. Ở mục Authorized JavaScript origins: Thêm URL trang web này (ví dụ: http://localhost:5500 hoặc http://127.0.0.1:5500 hoặc URL domain hosting của bạn).
  6. Sao chép Client ID và dán vào ô Google Client ID ở Bước 1.
Mẹo chống đơ treo và tránh rơi vào hòm thư rác (Spam):
  • Để độ trễ từ 1.5 đến 3 giây giữa mỗi email giúp tài khoản không bị Google gắn cờ spam.
  • Tool áp dụng cơ chế Asynchronous Yielding (nghỉ nhịp sự kiện) nên trình duyệt sẽ hoàn toàn mượt mà, không bao giờ bị đơ (Not Responding) dù gửi hàng trăm hay hàng nghìn dòng.
